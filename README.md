# Student Management System (React)

Admin and Teacher dashboards for BrightPath College, built with React, React Router and Bootstrap. Uses sample data held in React state (no backend).

## Run locally
1. `npm install`
2. `npm run dev`
3. Open http://localhost:5173

## Demo login
Any valid email and a password of 6+ characters. Choose Admin or Teacher to open that dashboard.

## Features
Public pages (Home, About, Login, Sign Up) with validation; Admin and Teacher dashboards with overview, student CRUD, teacher CRUD (admin), search, filter, pagination, settings and help.

## Deploy
Push to GitHub and import the repo in Vercel. `vercel.json` makes page refreshes work with React Router.
